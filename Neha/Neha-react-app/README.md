# Todo List App

A simple Todo List application built with React and Vite. Users can add, delete, and mark tasks as completed. The application stores tasks in the browser's local storage so they persist after refreshing the page.

## Features

Add new tasks
Delete tasks
Mark tasks as completed
View completed tasks separately
Persistent storage using Local Storage
Responsive and user-friendly interface

## Tech Stack

React
Vite
JavaScript
CSS
React Icons

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the URL shown in the terminal to view the application.
